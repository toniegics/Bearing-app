# Bearing

A mobile-first community and information app prototype for surveying, GIS and the wider geospatial industry.

## What it includes
- **Feed:** personalised industry news, AI-style summaries, industry alerts, sponsored posts
- **Marketplace:** jobs, equipment, hire, software, services, training, tenders
- **Community:** questions, polls, multi-photo posts
- **Events:** save and register
- **Library:** standards, regulations and guides with natural-language search
- **Profile:** followed topics, saved items, account trust
- **Moderation:** reporting, review queue, new-member holds, appeals

## Status
Front-end prototype using sample data. There is no backend, accounts or database, and nothing persists after a page refresh.

## Run it
Open `index.html` in a browser. No build step is needed.

## Roadmap

- Source registry with rights status for each news source
- Publisher dashboard for partner organisations
- Real image moderation service
